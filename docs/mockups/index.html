Converge/UX mockups

Three directions for the web UI

Each mockup covers the root page, review creation, and the review itself. Use the pill at bottom-right or keys 1/2/3 to switch screens.

D · Mix (chosen direction)

B's root page with an inline "Start a new review" row that expands into provider → repository, then A's create and review views. Header gets a separated brand block.
Open D →

A · Dashboard

Closest to today's layout, fewest surprises.
  • Resume cards first, single repo typeahead beside them
  • Changes grouped by ticket key with "select all N"
  • Three-pane review: tree with viewed checkboxes, sticky file header, next-file button
Open A →

B · Guided flow

Explicit steps, selection always visible.
  • Provider cards with health, filtered repo list, 4-step header
  • Sticky "Review composition" panel shows apply order and base
  • Full-width diff with file picker, Files / Changes / Conflicts tabs
Open B →

C · Dense, keyboard-first

Most change, most leverage for daily use.
  • One command box that searches reviews, repos, and ticket keys
  • Commit-stack sidebar while composing; j/k/space/t shortcuts
  • Single-scroll diff with per-line MR attribution
